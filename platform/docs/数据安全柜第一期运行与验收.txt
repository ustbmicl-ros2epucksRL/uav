数据安全柜第一期演示

入口：独立规划服务 /data-cabinet；地面站挂载 /network/data-cabinet。
规划平台和示范场景页导航已增加“数据安全柜”。

安装：在平台既有虚拟环境安装更新后的 requirements.txt；新增 cryptography>=41。
运行：沿用 scripts/run.sh。测试：PYTHONPATH=platform python -m pytest platform/tests/test_cabinet_demo.py -q（从项目根目录执行）。

操作：
1. 点击新建隔离演示，以所有者身份点击加密入柜。
2. 分别授权 A、B。
3. 切换 A，执行任务，查看训练/验证/测试样本及来源信息。
4. 切换 B，执行任务，只返回统计，不包含样本。
5. 切回所有者撤销 A；查看审计。
6. 切回 A，重新读取或执行均被拒绝；B 仍可读取自己的结果。

范围：城市场景合成特征，12 条样本、6 个分组；不是真实航迹分析。只有固定内置合成数据可入柜，不接受外部敏感数据上传。
角色切换是显式演示机制，所有者/A/B 均属于同一隔离演示会话，不是生产账号认证。每会话一份资产、两个主体，凭据保留浏览器内存，cookie HttpOnly/SameSite=Strict；服务端校验身份与授权，不信任请求体自报主体。生产登录、跨组织授权需另行接入。
数据置于 SENSE_DATA_DIR/cabinet-demo 临时子目录，演示密钥仅在服务内存。一小时会话到期；创建新会话时清理已到期会话。正常进程退出清理临时文件，异常终止可能留下不可恢复密文；不得用此机制保存正式数据。
会话状态仅存在单进程内，当前演示使用单 worker，不支持多 worker 负载均衡。会话最大 32 个，达到上限拒绝创建。
软件演示模式：未启用 Trustee、独立检查点或硬件证明。页面明确展示此边界，不声称防宿主 root。独立安全柜已有的保护组件可在第二期可信服务部署时接入。

- 主平台实际 app 的页面与静态资源检查通过；/network 挂载后的页面、静态资源、会话及鉴权检查通过。

- 截图：outputs/数据安全柜技术路线/第一期平台验收/。
浏览器复验：安装 Playwright 后，从项目根目录运行 node platform/tests/cabinet_browser_qa.cjs。
可用 CABINET_BASE_URL 指定服务地址（地面站地址含 /network），CHROME_BIN 指定本机 Chrome 可执行文件。

撤销边界：撤销阻止后续服务端任务和结果读取，不能收回授权期间已交付到客户端的结果。若需原始数据不出域，应在可信计算侧训练并只释放审核后的输出。
